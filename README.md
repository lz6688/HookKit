
# HookKit

一个适用于统一钩子方法的 iOS 开发者框架.

## Advantages and Disadvantages

Advantages:

* 通过使用批处理挂钩（如果可用）实现了性能提升.
* 能够使用来自您的自定义脚本的各类钩子库. [Shadow](https://github.com/jjolano/shadow) 
* 提供了此功能.

Disadvantages:

* 某些特定于图书馆的功能尚未实现(yet)
* 现有的调整内容需要重新编写/重新编译，以便使用 HookKit
